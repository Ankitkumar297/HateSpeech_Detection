04 / Model

How the model works

The training approach and results, including where this model can be wrong.

01

Text Ingestion & Regex Clean

Converts raw input to lowercase, strips URLs, handles `@mentions`, preserves hashtags, and removes extraneous symbols.

02

Context Preservation

Keeps common words and negation in the classifier input. Token stemming is displayed separately for inspection.

03

TF-IDF Extraction

Constructs word (1, 2) and character (3, 5) gram features to cover phrases and spelling variants.

04

Model Ensemble

Combines three-class TF-IDF and BERT predictions, then applies a conservative hate-risk check trained on a second dataset.

Combined Classifier (Primary)
Production Model

TF-IDF and BERT-tiny are combined with an independently trained hate-risk check. The safeguard catches some direct hate but also creates false positives; errors remain possible on unfamiliar wording.

Dataset & Classification Taxonomy
Class 0: Hate Speech

Language that attacks, denigrates, incites violence, or dehumanizes individuals based on protected attributes (race, religion, nationality, disability, gender, or sexual orientation).

Class 1: Offensive Language

Vulgar, profane, or hostile language that contains swear words or insults without expressing targeted bigotry against a protected minority group.

Class 2: Neutral Content

Everyday civil conversations, news articles, academic text, constructive feedback, and positive social media commentary.

05 / About

About this project

An experimental classifier for exploring text moderation.

Motivation & Approach

Online platforms often struggle to differentiate between casual coarse language (slang, venting, mild profanity) and targeted hate speech directed at identity groups.

This project uses labeled HateXplain and DynaHate data to distinguish Hate Speech, Offensive Language, and Neutral Discussions. TF-IDF and a fine-tuned BERT-tiny model feed the classifier. The reported accuracy is measured on held-out HateXplain posts; new wording can still be misclassified.

Real-time multi-class probabilistic scoring
Transparent token-level stemming inspection
Exportable audit trails in CSV and PDF formats
